# Projektziele

## Ziel

Dieses Projekt dient dazu, Funktionen von GitHub Copilot auszuprobieren.

## Beispielanwendung

Als Beispiel soll eine kleine Web-Applikation in Form eines Spiels entwickelt werden. Die Anwendung basiert auf:

- HTML für die Struktur,
- CSS für die Gestaltung,
- TypeScript für die Spiellogik.

## Inhalt des Spiels

Ein kleines Tamagotchi ähnliches Wesen, mit dem über Touch oder Mauszeiger interagiert werden kann. Das Spiel soll später per iFrame in andere Webprojekte eingebunden werden können. Das Wesen soll in Pixelart dargestellt werden.
